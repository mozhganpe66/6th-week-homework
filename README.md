# Project title: 
Current weather application

# project desciption: 
In this project, our aim is to show the details of weather condition for different cities with real data which is coming from weather API. 
We have a search engine that searches cities and based on city name user provides, trigers the API call and fetches data regarding weather like temperature, weather condition, humidity 
and wind speed. 

# How the project works:
This project uses the API call to weather api to fetch the real data regarding weather. In its javascript file when we click on search button, it triggers the function to featch the 
weather information from API and once the data is fetched, it renders it in the screen.

# features:
-search engine
- API call
- Icon for showing the weather based on hte weather condition
